## 🛠️ Tecnologias utilizadas

- ⚡ **Vite** — Bundler rápido e moderno
- ⚛️ **React + TypeScript** — Biblioteca para construção da interface com tipagem forte
- 💅 **Tailwind CSS** — Framework utilitário de estilização
- 🧩 **shadcn/ui** — Componentes de UI acessíveis e prontos para produção
- ☕ **Java / Backend** — foco profissional apresentado no conteúdo do portfólio

## 🚀 Como rodar localmente

> Antes de começar, você precisa ter o **Node.js** instalado em sua máquina.  
Recomendo usar o [nvm](https://github.com/nvm-sh/nvm#installing-and-updating) para instalar e gerenciar a versão do Node.

### Passo a passo:

```bash
# 1. Clone o repositório
git clone https://github.com/kelllyrobson/kellycodes-create

# 2. Acesse o diretório
cd kellycodes-create

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
